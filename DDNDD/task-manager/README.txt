TaskManager - Приложение для управления задачами

СТРУКТУРА ПРОЕКТА:
index.html      - главная страница
style.css   - стили script.js   - логика приложения
README.txt      - инструкция

КАК ЗАПУСТИТЬ:
1. Распакуйте все файлы, сохраняя структуру папок
2. Откройте файл index.html в любом браузере
3. Всё готово к работе!

ВОЗМОЖНОСТИ:
- Добавление задач (название + описание)
- 4 статуса: Очередь, В работе, Проверка, Готово
- Перетаскивание карточек мышкой между колонками
- Редактирование и удаление задач
- Фильтрация по статусу
- Сортировка по названию
- Автоматическое сохранение (localStorage)
- Уведомления о действиях

ТРЕБОВАНИЯ:
- Любой современный браузер
- Включенный JavaScript

ОСОБЕННОСТИ:
- Адаптивный дизайн (работает на телефонах)
- Данные сохраняются даже после закрытия браузера
- Простой и понятный интерфейс
